# נצרות · אימון למורי דרך

זהו מבחן תרגול אינטראקטיבי בעברית לתלמידי קורס מורי דרך. האתר פועל כאתר סטטי ומפורסם באמצעות GitHub Pages. השאלון נועד לתרגל לא רק זכירת מונחים, אלא גם חיבור בין אירוע, אתר, מסורת, עדה ומקור.

## תוכן ומקור

המאגר כולל **150 שאלות חזרה** בנושאי יסודות הנצרות, הברית החדשה, תחנות מרכזיות בחיי ישוע בארץ, השבוע הקדוש, אירועי פוסט־תחייה, היררכיה כנסייתית, נזירות וזרמים נוצריים. הוא כולל שאלות רב־ברירה ושאלות תשובה קצרה; כל שאלה כוללת תשובה, הסבר והפניית מקור פנימית ליחידת הלימוד הרלוונטית.

> השאלות נכתבו על בסיס שלוש מחברות הקורס שנמסרו לצורך העבודה — **נצרות א׳**, **נצרות ב׳** ו־**נצרות ג׳** — ועל בסיס תמלול מפגש החזרה למבחן. התמלול שימש לקביעת הדגשים ומבנה התרגול, והניסוחים נבדקו כדי שלא להנציח פליטות פה מן המפגש.

## שימוש באתר

האתר מציע:

- מסע מלא בן 150 שאלות בפיזור בין היחידות, כדי למנוע רצפים צפויים וחזרתיים.
- סימולציית מבחן בת 50 שאלות: 38 שאלות רב־ברירה ו־12 תשובות קצרות.
- תרגול מעורב מאוזן של 25 שאלות מכל היחידות.
- חזרה ממוקדת על טעויות ופתיחה ישירה של כל יחידת לימוד.

ההתקדמות ורשימת הטעויות נשמרות מקומית בדפדפן של המשתמש בלבד.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה מסכי המבחן |
| `style.css` | עיצוב רספונסיבי למובייל ולמחשב |
| `questions.js` | מאגר 150 השאלות, ההסברים והפניות המקור |
| `app.js` | לוגיקת המבחן, המשוב ושמירת ההתקדמות |
| `tools/quizcheck.js` | בדיקת תקינות המאגר, הפיזור ומבנה הסימולציה |

## פרסום

האתר מוגדר להתפרסם מ־`main` בתיקיית השורש, באמצעות GitHub Pages.
