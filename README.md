# נצרות · אימון למורי דרך

זהו מבחן תרגול אינטראקטיבי בעברית לתלמידי קורס מורי דרך. האתר פועל כאתר סטטי ומפורסם באמצעות GitHub Pages.

## תוכן ומקור

המאגר כולל **150 שאלות חזרה** בנושאי יסודות הנצרות, הברית החדשה, תחנות מרכזיות בחיי ישוע בארץ, השבוע הקדוש, אירועי פוסט־תחייה, היררכיה כנסייתית, נזירות וזרמים נוצריים. כל שאלה כוללת תשובה, הסבר קצר והפניית מקור פנימית ליחידת הלימוד הרלוונטית.

> השאלות נכתבו אך ורק על בסיס שלוש מחברות הקורס שנמסרו לצורך העבודה: **נצרות א׳**, **נצרות ב׳** ו־**נצרות ג׳**. לא שולבו עובדות ממקורות חיצוניים.

## שימוש באתר

האתר מציע מסע מלא בן 150 שאלות, תרגול מעורב של 25 שאלות, חזרה ממוקדת על שאלות שנענו לא נכון, וכן פתיחה ישירה של כל יחידת לימוד. ההתקדמות ורשימת הטעויות נשמרות מקומית בדפדפן של המשתמש בלבד.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה מסכי המבחן |
| `style.css` | עיצוב רספונסיבי למובייל ולמחשב |
| `questions.js` | מאגר 150 השאלות, ההסברים והפניות המקור |
| `app.js` | לוגיקת המבחן, המשוב ושמירת ההתקדמות |

## פרסום

האתר מוגדר להתפרסם מ־`main` בתיקיית השורש, באמצעות GitHub Pages.
